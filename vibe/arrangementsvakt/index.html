Hjem-skjerm-app

Installer Arrangementsvakt før bruk

Legg appen på Hjem-skjerm før operativ bruk. Dette gir rask tilgang, appvisning og bedre støtte for varsler.

iPhone / Safari

  1. Åpne appen i Safari.
  2. Trykk delingsknappen.
  3. Velg «Legg til på Hjem-skjerm».
  4. Trykk «Legg til».

Android / Chrome

  1. Åpne appen i Chrome.
  2. Velg «Installer app» dersom knappen vises, eller åpne menyen.
  3. Velg «Legg til på startsiden».
  4. Bekreft.
