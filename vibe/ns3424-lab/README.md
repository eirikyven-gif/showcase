# Byggtilstandslab

Første vurdering for Issue #2. Kildeappens inngangsside er et interaktivt læringslaboratorium om bygningsinspeksjon, med begrepsforklaringer, klassifiseringseksempler, risikovurdering, øvelse og quiz.

| Felt | Første vurdering |
| --- | --- |
| Navn | Byggtilstandslab |
| Bruksområde | Øve på å registrere synlige vedlikeholdsobservasjoner og prioritere videre undersøkelse |
| Kategori | Læring |
| Målgruppe | Byggdriftere, studenter og andre som lærer om bygningsvedlikehold |
| Status | Første vurdering fullført; bred kandidat, ikke kuratert |
| Foreslått slug | `ns3424-lab` |
| Demoens verdi | Viser hvordan en observasjon kan beskrives, vurderes og knyttes til et neste steg gjennom en interaktiv øvelse |
| Forenklinger | Egen generisk «observasjon / oppfølging»-modell; nye eksempler og spørsmål; ingen påstand om å gjengi eller tolke en standard; ingen ekte byggsaker |
| Rettighets- og personvernrisiko | Kildens faglige formuleringer og standardrelaterte tekst kan være beskyttet; derfor er alt demoinnhold skrevet fra bunnen av. Ingen eiendomsadresser, personer, inspeksjonsrapporter eller brukerinnsendinger. |
| Omfang | Én selvstendig statisk side med tre syntetiske observasjoner, lokal klassifisering og tilbakemelding. Ingen eksterne kall, ressurser, innlogging eller lagring. |

## Trygghets- og QA-notat

- Innholdet er generisk opplæringsmateriale, ikke faglig rådgivning eller en autoritativ standardtolkning.
- Eksempeldata er syntetiske og beskriver ingen identifiserbart bygg.
- Valg og tilbakemeldinger finnes bare i sidens minne og nullstilles ved oppfriskning.
- Direkterute: `/vibe/ns3424-lab/`.
- Distribusjon: Ikke publisert. PR/merge og One.com-deploy gjenstår.
