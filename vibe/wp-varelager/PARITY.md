## Explicit exclusions and safety substitutions

- Source is archived; inspected commit/tree above. Showcase baseline `b5e117cfe6d08f94ed9128523a854218b9d03009` had no route/catalog entry. The slug alone is not provenance.
- Authentication, WordPress capability checks, server/database persistence, private account/person records, private API/services, secrets, actual email, public share tokens/URLs, and private media are not reproduced. Synthetic values are labeled; state is local to the tab.
- Plugin specification/planning mentions features not exposed by the executable UI (bulk operations, partial returns, richer pricing/import workflows, broad share filtering/revocation, item deletion). These are not parity requirements and must not be added as demo behavior.
