Tilgangssimulering · bare lokal
Velg capabilities
Kildeappens capabilities
Valget simulerer UI-gating. Det er ikke innlogging eller sikkerhetskontroll.

Selvstendig nettlesersimulering av WP Varelager 2.3.0. Alle eksempelverdier er syntetiske. Ingen WordPress, PHP, innlogging, server, database eller API er tilkoblet. Kun tabell/galleri-valget bruker kildens hu_inv_view_mode-nøkkel; lagerdata er ikke persistent. Vedlegg bruker lokalt generert fixture-visning med metadata-only lifecycle. Delte lister lar deg velge og forhåndsvise en syntetisk kategoriliste og simulere utløpsdato lokalt. Kopiert rute inneholder bare en innebygd syntetisk listeslug, aldri token eller private data; e-post opprettes ikke.
