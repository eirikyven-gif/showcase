# showcase

Vibe-utstillingen publiseres under `https://yven.me/vibe/` med den manuelle **Deploy Vibe to one.com**-workflowen. Workflowen kjører bare fra `main`, starter med dry-run og krever smoke-test ved live-publisering. Se [publiseringsflyt](docs/deploy-vibe.md), [offentlig repooversikt](docs/repo-inventory-public.md) og [versjon](VERSION).

Førsterundeinventar for kandidatene dokumenteres ved hver rute-README. `vurderingsarbeid-fagskolen` er en syntetisk konseptdemo; kildens metadata kunne ikke verifiseres (404), og risiko/overlapp er markert som uavklart. Se [ruteinventaret](vibe/vurderingsarbeid-fagskolen/README.md).
