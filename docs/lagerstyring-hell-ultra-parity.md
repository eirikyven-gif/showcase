## Allowed substitutions and risk boundaries

WordPress auth/capabilities/nonces, server/database persistence, opaque magic-link secrets, real contact/person data, private media/services, external APIs and secrets remain removed. UI roles are explicitly illustrative, never authorization. State and selected files stay in the browser session and are cleared on reload. All sample identities, values and fixtures are synthetic; no source-private data/media is reused. Local list IDs are not access credentials.
